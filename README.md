# Dawit Yirdaw Mesfin — Portfolio Website

A personal portfolio website for Dawit Yirdaw Mesfin, a Computer Science graduate (Samara University, CGPA 3.57) working in IT support and event production in Addis Ababa, Ethiopia.

## What’s on the site

- **Loading screen** that shows the name and profession before the page opens
- **Interactive LED screen** at the top that lights up and spells the name; the lights glow when you move your cursor or finger over them
- **About, Experience, Projects, Skills, Certificates and Contact** sections
- Works on phones, tablets and computers, in light and dark mode
- Respects the “reduce motion” setting on a visitor’s device

## How to put the site online (GitHub Pages)

1. Create a new repository on GitHub, for example `portfolio`.
2. Upload `index.html` and `README.md` to the repository.
3. Open **Settings → Pages**.
4. Under **Branch**, choose `main` and the `/ (root)` folder, then click **Save**.
5. After a minute, your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.

## How to edit the site

Open `index.html` in any text editor, such as VS Code or Notepad.

- **Change text:** find the words in the file and replace them.
- **Add a project:** copy one `<article class="proj">…</article>` block in the Projects section, then change the title, description, technologies and link.
- **Change colours:** edit the values at the top of the `<style>` section, under `:root`.
- **Change the name on the LED screen:** in the script at the bottom, find `'DAWIT'` and replace it with your own text (short words work best).
